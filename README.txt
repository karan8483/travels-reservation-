TRAVEL RESERVATION MANAGEMENT SYSTEM — PRO ADMIN VERSION
=============================================================
VS Code + HTML + CSS + JavaScript.

RUN:
1. Extract ZIP.
2. Open folder in VS Code.
3. Install Live Server extension.
4. Right-click index.html -> Open with Live Server.
5. Test in Chrome.

ADMIN:
Open Admin from the navigation.
This demo admin page is intentionally simple and has no real secure login.

ADMIN FEATURES:
- Dashboard statistics
- Add/delete buses
- Add/delete routes
- View customers
- Filter bookings
- Cancel bookings
- Reset demo data

CUSTOMER FEATURES:
- Register/login
- Search routes
- Select seats
- Book
- Digital ticket / print
- My bookings
- Cancel booking

DATA:
Stored in browser localStorage. This is suitable for a college/demo project.
A production system needs a real backend, database, authentication, validation,
CSRF protection, authorization, and payment gateway.
